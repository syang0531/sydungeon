# 레벨 설계 — 얼음 성채

> 이 문서는 `python tools/gen_level_doc.py ice`가 만든다. 조각을 고치면 다시 돌린다. 그림과 표는 게임이 읽는 파일(`structure/ice/*.nbt`, `worldgen/**`)에서 그대로 읽어 온 것이라 모드와 어긋날 수 없다. 설명 문장만 사람이 쓴다 (`tools/gen_level_doc.py`의 `INTRO`·`NOTES`).

## 1. 한눈에

눈 덮인 땅에 선 성이다. **아성**이 한가운데 서고 그 사방으로 **성벽**이 뻗어 49×49 안뜰을
두르며, 네 귀퉁이에 **탑**이 올라간다. 아성 바닥의 구멍으로 사다리가 14칸 내려가면 돌벽돌
**얼음 창고**고, 그 안쪽에 **서리 군주**가 있다.

**한 판:** 성문으로 들어가 안뜰과 순찰로를 돌며 탑의 스트레이를 상대하고 → 아성 → 사다리 →
얼음 창고 미로(가루눈·푸른 얼음·북극곰) → 통로 셋 뒤 보스. 이기면 **마법 부여 다이아 방어구
한 조각 + 서리 걷기 II 책**이 확정이다. 서리 걷기는 마법 부여대에서 나오지 않는 보물
마법이라, 이 책이 유일한 길이다.

| 항목 | 값 |
|---|---|
| 생성 단계 | `surface_structures` |
| 바이옴 | `#sydungeon:has_structure/ice` |
| 간격 / 최소거리 | spacing 36 / separation 12 |
| 직소 깊이 | 14 ~ 22 (`sydungeon:ranged_jigsaw`) |
| 시작 풀 | `start` |
| 조각 / 풀 | 23개 / 14개 |

## 2. 조립 원리

### 성벽은 한 조각일 수 없다

49×49 한 장으로 만들면 아성이 그 상자 **안에** 매달린다. 그러면 `CLAUDE.md` §10대로
**울타리가 자손에게 상속되어** 지하 창고까지 성벽 상자에 갇힌다 — 아래를 가리키는 직소를
달아도 자식이 거부될 뿐이다. 피라미드는 그걸 노린 것이지만 여기서는 사고다.

그래서 성벽을 **가운데가 빈 여덟 조각**(벽 넷 + 탑 넷)으로 나눈다. 상자가 안뜰을 비워 두므로
상속이 일어나지 않고, **시작 조각인 아성**에서 내려가는 가지는 아무것도 가두지 않은 자리에서
자란다.

### 고리는 결정적 기하로 닫힌다

아성이 사방으로 벽을 부르고, **북벽과 남벽만** 자기 양 끝에서 탑을 부른다. 둘만 부르는 이유가
있다 — 탑은 두꺼운 모서리와 두 팔로 되어 있어서, 한 번만 잘못 돌아가면 탑이 안뜰 안쪽에
박힌다. 동·서벽도 부르게 하면 같은 탑을 두 방향에서 불러 **어느 쪽이 먼저 놓이느냐에 따라
방향이 달라진다.** 한 번만 부르면 회전이 하나로 정해진다 (§13).

바닐라는 돌려는 주지만 **뒤집어 주지는 않으므로** 북서용과 북동용이 서로 거울이다. 탑 하나를
만들고 x를 뒤집어 다른 하나를 만든다 — 마법사의 탑의 `corner_right`와 같은 수법이다.

깊이는 지상 전체가 **2**밖에 쓰지 않는다: 아성 → 벽 → 탑.

### 산에 서는 법

눈 비탈·서리 봉우리·그로브는 **산 바이옴**이라 바닥이 평평하지 않다. `terrain_adaptation`은
`beard_thin`이고, 그 위에 **벽과 탑이 기초를 일곱 칸 아래로 끌고 내려간다.** 시작 조각은
바닥이 지표에 고정되지만(§18) 자식은 직소 높이로만 놓이므로 얼마든지 깊어도 된다. 늪의
말뚝에서 배운 것을 그대로 쓴 것이다.

안뜰은 조각이 덮고 있으므로 **평평하게 깎인다.** 성이 비탈에 앉으면 한쪽은 기초가 드러나고
한쪽은 땅에 묻힌다 — 성이라면 그래야 한다.

### 위험은 트리거가 없다

가루눈 웅덩이와 푸른 얼음 바닥. 둘 다 **밟아서 터지는 것이 아니라 그냥 거기 있는 것**이라,
플레이어가 오기 전에 몹이 먼저 발동시켜 버리는 §12의 문제가 없다. 가루눈은 가죽 부츠가
있으면 건널 수 있고, 그래서 **모든 상자의 첫 풀에 가죽 부츠가 들어 있다.**

## 5. 조각


그림은 조각 하나를 **층마다 한 장씩** 블록 단위로 그린 것이다. 같은 층이 이어지면 `y = 2–5`처럼 묶었고, 마지막 두 장은 가운데를 자른 세로 단면이다. 분홍 점이 직소, 화살표가 그 직소가 보는 방향이다 — **마주 본 직소끼리만 붙는다.**

### `keep` — 21×21×21 — 3×3×3 셀

시작 조각. 21×21×21 세 층이고 사방에 문이 하나씩 있어 **그 넷이 성벽을 부른다.** 바닥의
3×3 구멍이 이 던전의 유일한 아래 방향 직소다.

게임은 시작 조각을 **바닥으로 고정**하므로(`minY + 1`이 지표) 아성은 기초를 아래로 못 끌고
내려간다. 대신 벽과 탑이 자식이라 일곱 칸씩 내려간다 (§18).

**어느 풀에 있나** — `start` (가중치 1)

| 직소 위치 | 향 | name | target | pool |
|---|---|---|---|---|
| (10, 0, 0) | ▲ 북 | `ice_wall` | `ice_wall` | `ice/panels_end` |
| (0, 0, 10) | ◀ 서 | `ice_wall` | `ice_wall` | `ice/gate` |
| (12, 0, 10) | ◇ 아래 | `ice_down` | `ice_down` | `ice/down` |
| (20, 0, 10) | ▶ 동 | `ice_wall` | `ice_wall` | `ice/panels` |
| (10, 0, 20) | ▼ 남 | `ice_wall` | `ice_wall` | `ice/panels_end` |

**뚫린 면** — 서: z 1–19, y 1–20 (22칸) / 동: z 1–19, y 1–20 (22칸) / 북: x 1–19, y 20–20 (10칸) / 남: x 1–19, y 1–20 (22칸) / 아래: x 9–11, z 9–11 (8칸) / 위: x 0–20, z 0–20 (401칸)

**코드가 지은 첫 판이다.** 조각은 출발점이고 예쁘게 만드는 일은 개발 클라이언트에서 한다
(`CLAUDE.md` §16). **조각이 전부 한 변 48 이하라 하나도 빠짐없이 손으로 다시 지을 수 있다** —
`verify()`가 그걸 검사한다. `python tools/workshop.py ice`로 전부 깔린다.

- **성벽이 속이 꽉 차 있다.** 일곱 칸 두께가 통짜라 안이 없다. 안에 회랑을 뚫고 탑과 이으면
  순찰로가 두 층이 된다
- **아성 내부가 휑하다.** 세 층에 모닥불과 상자 하나뿐이다. 무기고·침소·지도실이 들어갈 자리다
- **얼음 창고가 지하감옥과 같은 모양이다.** 통로·교차로·막다른 방. 얼음을 캐던 구덩이나
  얼어붙은 우물처럼 이 던전만의 칸이 필요하다
- **북극곰이 스포너로만 나온다.** 우리 안에 갇힌 곰이 문을 부수고 나오는 그림이 더 낫다
