# SY Dungeon

마인크래프트 자바 에디션 모드. **손으로 지은 조각을 직소가 이어 붙여, 매번 다른 던전을 만든다.**

## 무엇이 나오나

**지하감옥** — 평원·숲·타이가의 지표에 선 돌벽돌 정자에서 사다리로 내려가면 미로가 시작된다. 직선 통로·십자 교차로·계단이 7×7 격자로 이어지고, 통로 옆 철창 뒤 감방에는 상자가, 막다른 경비실에는 스포너가 있다. 던전마다 깊이가 다르고 벽은 금 가고 이끼 끼어 있다. 허브에서 뻗은 복도 하나는 세 배 큰 보스방으로 이어지고, 거기서 좀비말을 탄 간수장과 무장 경비를 잡으면 트라이얼 스포너가 마법 부여 다이아 장비를 뱉는다. `/locate structure sydungeon:dungeon`으로 찾는다.

**대피라미드** — 사막에 선 밑변 91칸, 높이 46칸의 사암 피라미드. 북면의 문으로 들어가면 9×9칸 미로가 있고, 중앙 우물의 사다리가 21칸짜리 묘실 바닥 한가운데로 올려보낸다. 올라서는 순간 스포너에 둘러싸인 채로 잠들지 못한 파라오와 싸운다. 이기면 **흑요석 14개와 화염과 강철, 마법 부여 다이아 장비 하나** — 네더 포탈과 마법 부여대다. 가는 길에는 허스크가 묻힌 모래 소굴과 솔질해서 파내는 수상한 모래가 있다.

**마법사의 탑** — 타이가에 선 밑변 29칸, 높이 56칸의 **둥근** 탑. 서쪽 현관으로 들어가면 한 층이 7×7 방 아홉 칸이고, 여덟 층을 올라간다. **층마다 계단이 다른 칸에 있어서** 매 층 걸어서 찾아야 한다. 거리 한가운데에는 스포너가, 막다른 방에는 상자가 있다. 그리고 어느 층은 칸이 하나 모자란다 — **문이 하나도 없는 방**이 있고, 돌로 막힌 문을 파야 나온다. 4층 문 너머는 **도서관**이다. 벽이 전부 책장이고 단상의 **마법 부여대**가 책장 열다섯에 둘러싸여 30레벨을 바로 준다. 8층은 대마법사의 성소와 **불 붙이지 않은 네더 포탈 틀**. 그를 이기면 **엔더의 눈 넷과 불사의 토템**이 나온다.

계획: 바이옴마다 하나씩 — 네더와 엔드까지. 전체 설계는 [docs/concepts.md](docs/concepts.md).

## 목적

**파밍과 채굴 없이, 탐험만으로 엔드 콘텐츠에 닿는다.** 시작할 때 나무와 돌 정도는 손으로 캐지만, 그 뒤로는 던전을 찾아 들어가고 보스를 잡는 것이 진행의 전부다. 밀밭을 갈지 않고 광맥을 찾지 않는다. 바닐라가 파밍·채굴로 주던 것을 던전이 준다 — 침대와 횃불부터 흑요석, 블레이즈 막대, 네더라이트, 엘리트라까지. 던전마다 "여기서만, 반드시" 나오는 보상이 하나씩 있다.

## 어떻게 만들어지나

조각은 크리에이티브에서 구조물 블록으로 저장한 `.nbt`, 이어 붙이는 규칙은 바닐라 worldgen JSON이다. Java는 바닐라 직소가 못 하는 일이 생길 때만 쓴다. 조각을 바꾸고 싶으면 코드가 아니라 월드에서 바꾼다 — [CLAUDE.md](CLAUDE.md)와 [docs/design.md](docs/design.md).

던전마다 **레벨 설계 문서**가 있다. 조각을 층마다 한 장씩 블록 단위로 그리고, 그것들이 어떤 규칙으로 이어 붙는지를 적은 것이다 — [docs/levels/](docs/levels/).

| 항목 | 값 |
|---|---|
| Minecraft | 26.2 (Java Edition) |
| 모드로더 | NeoForge 26.2.0.88 |
| Java | 25 |
| modid | `sydungeon` |
| 배포 | CurseForge — [PUBLISHING.md](PUBLISHING.md), 등록 정보는 [docs/curseforge/등록정보.md](docs/curseforge/등록정보.md) |

```bash
./gradlew build        # 빌드
./gradlew runClient    # 클라이언트 실행
```

모드 빌드 없이 보려면 데이터팩으로 묶어 26.2 월드에 넣는다:

```bash
python tools/pack_datapack.py "<월드 경로>"
```

그리고 게임에서 `/reload` 후 `/place jigsaw sydungeon:dungeon/start sydungeon:door 10 ~ ~ ~`.
